# Legacy Controller 0.1.0 — предварительная сборка

Программа для Windows x64. В архиве находится готовый `Legacy.exe` со встроенным .NET Runtime. Visual Studio и отдельная установка .NET для запуска не нужны. Распакуйте архив в постоянную папку и запускайте EXE от обычного пользователя.

**Статус:** сборка и проверки логики пройдены; окно проверено на Windows 11. Настоящего DualShock 3 у разработчика нет. USB/Bluetooth, вибрация и работа виртуального контроллера в играх ещё не прошли аппаратную проверку. Это версия для первого тестирования другом, а не завершённый продукт по всему ТЗ.

## Начать с DualShock 3

1. На компьютере, к которому подключён геймпад, откройте официальный репозиторий: https://github.com/nefarius/DsHidMini/releases
2. Установите подходящий официальный подписанный выпуск по инструкции https://docs.nefarius.at/projects/DsHidMini/ . Legacy сам драйверы не скачивает и не устанавливает. Не отключайте проверку подписи или Secure Boot.
3. Подключите геймпад USB-кабелем с передачей данных. Откройте DsHidMini ControlApp и проверьте обнаружение.
4. Для простого использования в играх выберите **XInput mode**. Этот режим предоставляет драйвер DsHidMini. В Legacy выберите появившийся `XInput controller`, нажмите Connect и откройте Controller Tester. Для определения нужного слота отключите другие XInput-геймпады на время первого теста.
5. В этом режиме изменения профиля Legacy видны в предпросмотре, но не меняют ввод, который игра получает напрямую от DsHidMini. Настройку конкретной игры можно выполнять средствами самой игры или Steam Input.

### Обработанный ввод Legacy → виртуальный Xbox

Это отдельный, экспериментальный путь. Он нужен для передачи переназначений и deadzone из Legacy в игру.

1. В DsHidMini ControlApp выберите **DS4Windows mode**. Переподключите геймпад. На странице «Устройства» Legacy должен появиться HID с VID/PID `7331:0001`.
2. Для виртуального выхода требуется ViGEmBus, установленный отдельно. Официальный источник: https://github.com/nefarius/ViGEmBus/releases . Этот проект снят с поддержки; он не является обязательным для запуска Legacy или прямого XInput-режима. Не используйте случайные зеркала и старые автообновляторы. Обоснование выбора ниже.
3. Настройте HidHide по официальной инструкции: https://docs.nefarius.at/projects/HidHide/Simple-Setup-Guide/ . Добавьте **именно текущий Legacy.exe** в разрешённые приложения, скройте физический DS3 и включите скрытие. Виртуальный Xbox скрывать не нужно. При переносе EXE обновите разрешённый путь. Правила должны позволять Legacy читать DS3, а игре — видеть только виртуальный выход. Закройте другие программы-переназначатели для этого контроллера.
4. В настройках Legacy включите виртуальный Xbox и подтвердите, что HidHide настроен. Это подтверждение пользователя, а не автоматическая проверка правил.
5. Выберите HID `7331:0001`, нажмите Connect. При успешном подключении backend статус сообщает о виртуальном Xbox. При отсутствии драйвера появится ошибка и повторные попытки; Disconnect прекращает их.
6. Откройте Controller Tester, проверьте сырой и обработанный ввод. После этого запустите игру. Если игра получает двойной ввод, остановите виртуальный выход и исправьте правила HidHide.

Преобразование XInput → виртуальный XInput в этой версии запрещено, чтобы собственный виртуальный контроллер не становился источником ввода.

### Bluetooth

Требуется совместимый адаптер и BthPS3: https://docs.nefarius.at/projects/BthPS3/ . Сопряжение выполняется по инструкции этого проекта, не средствами Legacy. Режим DsHidMini задаётся отдельно для USB и Bluetooth: убедитесь, что выбран нужный режим для обоих подключений. Фактическая работа Bluetooth в Legacy не проверялась.

## Реализовано

- WPF-интерфейс: dashboard, список устройств, визуальный тестер, настройки управления, профили, настройки и ссылки на драйверы.
- Поиск HID gamepad/joystick и четырёх слотов XInput в фоновой задаче.
- Декодирование DS3 через DsHidMini **DS4Windows mode** по официальному формату: кнопки, крестовина, оба стика, аналоговые L2/R2, PS.
- Чтение XInput, тест вибрации и передачa вибрации виртуального Xbox в DS3 backend.
- Радиальная deadzone и чувствительность стиков, инверсия Y, обмен стиков, переназначение цифровых кнопок, обмен триггеров, их deadzone и чувствительность.
- Отдельный необязательный backend ViGEm; ввод и виртуальный выход имеют интерфейсы для дальнейшего расширения.
- Повторные попытки подключения, нейтральный выход при тайм-ауте чтения, отключение виртуального выхода и остановка вибрации при завершении соединения.
- Создание, переименование, дублирование, удаление, импорт и экспорт профилей JSON. Назначение профиля имени процесса игры и выбор первого совпадения.
- Версия формата настроек, валидация, сохранение через временный файл, резервная копия повреждённых или неизвестных версий перед использованием значений по умолчанию.
- Автозапуск через запись текущего пользователя (только при включении), автоподключение, настраиваемая пауза опроса, ограниченный по размеру журнал.
- Просмотр версии и сведений о подходящих активных драйверах через Windows CIM. Это не полная проверка Driver Store и исправности установки.

Настройки: `%LOCALAPPDATA%\LegacyController\config.json`. Журнал: `legacy.log`, максимум около 2 МБ плюс одна предыдущая копия. При ошибке настроек оригинал сохраняется как `config.json.backup-*`. Перед обновлением достаточно оставить эту папку на месте. Миграции между выпущенными форматами пока не требуются: существует только версия 1.

## Ограничения

- Целевые системы — Windows 10 22H2 x64 и Windows 11 x64; фактический запуск проверен только на Windows 11 Pro 10.0.26200.
- Это не универсальный HID-декодер: прочие HID видны в списке, но Connect не реализует их произвольные layouts. Обычный DS3 без подходящего драйвера, SXS/SDF/GPJ/CGP не декодируются.
- USB/Bluetooth транспорт не угадывается по имени; интерфейс показывает, когда API не предоставляет эти сведения.
- Аналоговое давление лицевых кнопок и motion sensors не передаются. XInput не предоставляет аналога для всех кнопок.
- Нет автоматической установки драйверов, настройки HidHide, проверки совместимости со всеми играми, подписанного установщика и подписи издателя EXE.
- Метаданные `Legacy Controller Community` — название проекта, не удостоверенный издатель.
- Только русский язык и тёмная тема. Канал обновлений ещё не существует. Настройка уровня логирования и расширенные анимации не реализованы.
- Один активный контроллер; после изменения XInput-слота или HID-пути может понадобиться выбрать устройство заново. Частота HID определяется также драйвером, а пауза после отчёта не является гарантией задержки.
- Разделение core/backend/UI и DI реализованы. Полный перенос представлений из code-behind в MVVM ещё не завершён.
- Ручная настройка HidHide обязательна для предотвращения двойного ввода в дополнительном режиме; программа не подтверждает её автоматически.

## Почему два пути вывода

DsHidMini имеет собственный XInput mode: https://docs.nefarius.at/projects/DsHidMini/v3/XInput-Mode-Explained/ . Для простого использования DS3 это позволяет обойтись без ViGEmBus. Но такой поток не проходит через обработку Legacy.

ViGEmBus и клиент сняты с поддержки: https://docs.nefarius.at/projects/ViGEm/End-of-Life/ . Они оставлены только как необязательная реализация интерфейса виртуального выхода для испытания обработанного ввода. Современный VirtualPad предоставляется коммерческим партнёрам: https://docs.nefarius.at/projects/VirtualPad/ . Доступа к нему у проекта нет. Его API не имитируется и не выдумывается.

Формат чтения и output report сверены с `driver/DsHid.c` и `driver/HID.Reports.c` официального https://github.com/nefarius/DsHidMini . Клиент ViGEm сверялся с исходниками https://github.com/nefarius/ViGEm.NET . Аппаратные результаты из документации этих проектов не считаются результатами тестирования Legacy.

## Сборка исходников

Нужен Windows x64 и .NET 10 SDK. Использован SDK 10.0.403. В корне исходников запустите `./build.ps1` в PowerShell. Он запускает тесты и публикует self-contained single-file EXE в `release`. Runtime и native-библиотеки при необходимости извлекаются средствами .NET в пользовательскую временную область. Обычная работа не требует администратора.

Зависимости: HidSharp 2.6.4, Nefarius.ViGEm.Client 1.21.256, Microsoft.Extensions.Hosting 10.0.0. Лицензии включены в папку `licenses`. Драйверные бинарники в архив не включены.

## Что проверить другу

1. Запуск EXE, установка драйверов из официальных источников, обнаружение DS3 по USB.
2. Каждую кнопку отдельно, диагонали крестовины, крайние и центральные положения стиков, плавное нажатие L2/R2.
3. Вибрацию и её остановку; отключение кабеля при нажатой кнопке — игра должна получить отпускание, программа не должна зависнуть.
4. Повторное подключение, Bluetooth отдельно, работу профилей после перезапуска.
5. В дополнительном режиме — появление одного доступного игре Xbox-контроллера, переназначение A/B и deadzone непосредственно в игре.
6. Название игры, версию Windows, версию DsHidMini, режим, оригинальность геймпада/модель клона и точный текст ошибки записать в `TEST-REPORT.md`. Журнал можно передать разработчику вручную; Legacy ничего не отправляет автоматически.

Если задача — только подключить геймпад для игры, начать стоит с прямого XInput mode DsHidMini. Проверка дополнительного выхода — отдельный шаг.
