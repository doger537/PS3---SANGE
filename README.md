# Legacy Controller

Приложение для подключения геймпада **Sony DualShock 3 к Windows**. Это не программа для самой консоли PlayStation 3.

**Предварительная версия 0.1.0.** Сборка и 15 проверок логики пройдены локально. Работа с настоящим геймпадом, Bluetooth, виртуальным Xbox и играми ещё требует проверки на оборудовании.

## Скачать и запустить

1. Откройте [Releases](https://github.com/doger537/PS3---SANGE/releases).
2. В последнем предварительном выпуске раскройте **Assets** и скачайте **LegacyController-win-x64.zip**.
3. Распакуйте ZIP в постоянную папку и запустите **Legacy.exe**. Отдельный .NET Runtime для Legacy не нужен.
4. Для геймпада установите [DsHidMini из официального источника](https://github.com/nefarius/DsHidMini/releases/latest), подключите DualShock 3 кабелем USB с передачей данных и начните с **XInput mode**.
5. В Legacy: **Устройства → Обновить → XInput controller → Подключить выбранный → Controller Tester**.

Пока идёт первая сборка, список Releases может быть пуст. Её состояние видно в [Actions](https://github.com/doger537/PS3---SANGE/actions).

Для первого теста оставьте дополнительный виртуальный Xbox выключенным. В прямом XInput-режиме ввод в игры обеспечивает DsHidMini; переназначения Legacy действуют только на предпросмотр. Передача обработанного ввода в игру требует отдельно настроенных ViGEmBus и HidHide, описанных в инструкции. ViGEmBus снят с поддержки и не устанавливается автоматически.

## Исходники и сборка

`src/` — приложение WPF и backends; `tests/` — проверки обработки ввода и конфигурации.

На Windows с .NET 10 SDK выполните `./build.ps1`. Готовый self-contained single-file EXE будет в `release/`.

GitHub Actions выполняет тесты, собирает Windows x64 и публикует ZIP с программой, инструкцией, лицензиями и SHA-256. Драйверы в пакет не включены. EXE не подписан сертификатом издателя.
