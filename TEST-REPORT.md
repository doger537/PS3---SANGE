# Проверки Legacy 0.1.0

Дата: 03.11.2026. Среда: Windows 11 Pro 10.0.26200 x64; SDK 10.0.403.

## Проверено разработчиком

- Release x64: сборка без ошибок.
- Self-contained single-file публикация: успешно; настоящий Legacy.exe сформирован.
- Запуск опубликованного EXE: окно открывается.
- Визуально: тёмный dashboard и тестер без устройства.
- Поиск: страница устройств открывается, при отсутствии контроллера список пуст.
- Connect без выбранного устройства: понятное сообщение, приложение продолжает работать.
- Автоматические проверки core: 15 PASS (deadzone, радиальное ограничение, переназначение и инверсия, обмен стиков, валидация профиля и версии config, neutral DS3 report, кнопки/оси/триггеры, неверный report, JSON roundtrip, повреждение и backup, mapping roundtrip, обработка триггеров, null-профиль).

Результат первого теста границы deadzone был исправлен: сравнение float теперь использует допуск 1e-6 вместо точного равенства. Протокол не скрывает эту коррекцию теста.

## Не проверено / нужно оборудование

Физическое обнаружение DS3, права доступа к HID, USB-ввод, Bluetooth, реальная вибрация, обратная вибрация из игры, успешное создание виртуального Xbox через установленный ViGEmBus, отсутствие двойного ввода, переподключение оборудования, задержка и длительная стабильность, Windows 10. Никаких аппаратных PASS не заявляется.
